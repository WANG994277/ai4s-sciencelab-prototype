# AI4S 科研平台产品原型

双击 `index.html` 即可打开。原型为纯前端静态文件，不需要安装依赖，也不会调用真实模型、算力、数据或实验设备。

### 课题空间导航：以解决关键问题为主线

课题空间现为「空间概览、关键问题、科研任务、作业监控、空间资产」。协作与评审进入科研任务，研究结论随任务结果及报告保存，假设验证与当前判断归关键问题。任务区展示待开始、运行中、待确认、已完成并支持状态筛选；执行状态与产出确认状态分别呈现。成员管理、讨论、指定方案或产出版本送审、反馈及确认在任务内处理，分配给当前示例用户林夏的评审事项并入工作台现有待我处理。跨任务汇总通过阶段研究总结任务完成。科研任务可以是文献研读、模拟计算、读+算联合研究或实验方案工作，不等同于“算”。一个任务下可有多次科研超级中枢执行会话；空间内采用三栏任务工作区，可新建会话、确认计划并直接运行演示，不必返回全局中枢。作业监控页可调整课题参数、运行合成示例计算并比较指标，同时展示模型、数据版本及验证链路。示例公式与数字不是真实科研模型，不可用于科学决策。原“深度研究台”从一级导航移出，保留为任务内的工作视图。科研活动归入空间概览及完整动态，过程文件和正式科研资产归空间资产。空间资产（2026-10-13 晚调整）分「空间文件」（全部会话沙箱文件）与「科研资产」（资源中心加载 + 已发布，按成果文件、数据集、模型、MCP、智能体、Skill、知识库分类）两个页签；发布 = 草稿/文件转为科研资产，上架 = 推到科研资源中心；Skill 可在科研任务的“任务上下文”中由会话沉淀并保存到空间资产。原有旧入口会转到新的对应页面。不同课题的概览、问题和研究材料使用对应示例内容，不再混用合成橡胶数据。

### 2026-10-01 科研工作台视觉试版

本次职责收拢版已取代原“定时研究”独立模块与大块关注课题概览：研究入口 → 待我处理 / 我的研究任务 → AI 研究建议 / 最近产出 → 我的课题与最近工作。任务视图包含全部任务、运行中、待我确认、已结束、定时计划。定时计划与单次执行记录明确分离；可查看某计划的执行记录。AI 建议不再直接采纳成任务，而是同步到科研中枢，由用户在中枢确认计划后执行；定时计划在“我的研究任务”中新建。协作评审、会签和 AI 结果确认汇总到待办，无需行动的动态归通知，正式协作留在课题空间。可演示待办处理、任务结果确认、定时计划启停和建议采纳；刷新后重置，不触发真实后台工作。

采用 UI UX Pro Max 与 Frontend Design 的指导，保留原有三层级架构，仅重设计个人科研工作台。浅色高密度业务区配合深色研究输入区，去除重复英文装饰标题；新增执行轨迹、AI 下一步建议、定时研究与跨课题最近产出。推荐可采纳或暂不采纳，定时任务可新增和暂停/启用，研究问题可带入科研中枢。所有状态仅在当前浏览器会话演示，刷新重置；不会实际调度任务、上传文件或调用模型。已检查 1080、1280、1440 像素桌面布局，未覆盖移动端工作环境。

## 页面范围

- 门户首页：AI+油气科研价值主张、产业场景视觉、读算做能力全景、热门科研资源、科研成果案例、平台动态与科研活动
- 平台 AI 架构表达：科研中枢大模型负责科学理解与专业推理，科研中枢智能体负责任务规划、资源编排与流程执行
- 热门科研资源：按知识、数据、模型、工具、技能、工作流、Agent及应用七类展示
- 门户信息密度采用云平台式布局：紧凑区块、左侧资源类目导航、右侧 3×2 资源矩阵
- 首屏下方收敛为单行油气科研场景导航，减少重复入口与视觉割裂
- 首屏右侧采用“科研中枢数字孪生场”动态主视觉，以知识与数据输入、AI 推演、多尺度模型和实验反馈体现 AI4S 前沿感
- 平台分层能力已融入“读—算—做”全流程：资源中心供给能力，科研中枢理解与调度，工作台承接个人任务，课题空间完成协作与资产沉淀
- 科研资源中心以资源类型为主目录，以“读—算—做”为辅助筛选；算力由 AI 中台管理，不作为科研资源类型展示
- 资源卡展示提供方、共享方式、浏览量、使用量及适用科研阶段；实验设施仅包含实验设备、试剂与实验条件
- 科研资源支持地球科学、材料科学、合成生物学领域筛选，并根据知识、数据、模型、工具、实验设施、技能、工作流、Agent及应用切换专属筛选维度
- “技能”作为独立资源类型，表达可被 AI 或 Agent 直接调用的原子科研能力；工具提供基础执行能力，工作流组合多个技能，Agent 负责任务规划与动态调用
- 资源卡采用图标化提供方、共享方式、浏览量和使用量表达，并增加更现代的层次、悬停和状态样式
- 公共科研资源中心：未登录可浏览，以资源类型为主目录，以科研阶段和科学领域作为组合筛选
- 科研工作台：以个人科研驾驶舱组织今日概览、智能研究入口、跨课题待办和科研中枢运行动态；同时提供明确标注的“当前关注课题”窗口，汇聚该课题的动态、产出和里程碑，但不改变全局工作范围
- AI 科研中枢
- 我的资源：按“可用资源、我创建的、我的收藏、我的申请”组织个人资源，并叠加知识、数据、模型、工具、实验设施、技能、工作流、Agent及应用等资源类型筛选；可快捷进入集团科研资源中心
- 我的课题空间：集中查看本人负责或参与的正式协作课题；全局导航只提供一个目录入口，不展开具体课题列表
- 科研管理：集团门户顶层入口，位于“科研资源”之后，覆盖立项、成果、外协、人才、考核、日程、过程七类管理域，并为每类配置专属管理智能体
- 科研项目管理：登录后左侧「科研管理」分组下的智能体目录，按立项、过程、外协、成果、人才、考核、日常七类展示 16 张卡片，支持分类筛选与名称/简介搜索；「开始使用」目前仅展示能力和未接入提示，不调用真实智能体
- 科研规范：集团门户顶层入口，位于“科研管理”和“科研社区”之间，按科研伦理、数据安全、AI 辅助科研、实验安全、知识产权、成果发布与过程归档提供行为指引
- 平台小助手：默认位于集团门户页面右下角，可拖动并跨门户页面保持位置；支持文字、截图/文件上传、粘贴截图与语音输入，统一回答平台导航、功能使用、权限申请和科研流程问题，不替代科研中枢智能体
- 登录后工作区：侧栏底部提供折叠/展开操作，不重复展示登录人；顶栏提供“帮助助手”入口，随时打开平台小助手
- 课题空间：空间概览、关键问题、科研任务、作业监控、空间资产；任务详情保留深度工作视图并承载协作评审，结论归任务结果及报告

## 建议体验路径

1. 门户首页 →「科研资源」，在未登录状态浏览公共资源
2. 在公共科研资源中心切换“读 / 算 / 做”，并体验“技能”分类及专属筛选
3. 返回门户 →「描述科研问题」或「新手上路」
4. 沿首页浏览“读—算—做”能力地图，在热门资源区切换六个类目，再查看成果案例与科研活动
5. 进入科研工作台，查看今日概览、科研活动和待办，再通过「发起智能研究」进入科研中枢
6. AI 科研中枢 → 点击发送，观察计划从执行中变为完成
7. 从科研活动或「我的课题空间」进入「高性能合成橡胶」课题空间，查看空间概览
8. 从「关键问题」确认假设和验证标准，经「科研任务」协作、评审及「作业监控」推进，在任务结果中核对阶段结论并回到关键问题更新判断，在「空间资产」查看文件和正式资产；在具体任务中可打开深度工作视图
9. 进入“我的资源”查看授权和使用状态，并通过快捷入口返回集团科研资源中心
10. 从左侧「我的课题空间」查看全部正式协作课题，再进入具体课题空间
11. 进入具体课题后观察左侧导航整体切换；返回全局科研后不在顶部展示课题列表
12. 返回集团门户，从外层顶导进入“科研管理”，查看七类管理域及对应智能体，再进入“科研规范”按场景查询行为准则

## 设计说明

工作台布局修正：导航统一为「科研超级中枢」，去除内容区重复的「科研工作台」大标题。保留四组概况指标，研究入口与 AI 建议采用原生双列布局，建议操作固定在文字列内；下方分别呈现待办与执行任务、最近产出、课题入口。窄屏顺序堆叠，不混用全局和课题导航。

本轮工作台调整：研究会话入口与 AI 建议并排，会话区提高输入高度；欢迎语结合当天待办和运行中任务数量；模型选择默认「科研中枢模型」，可切换厂商原型已有的模型示例。模型选项仅为原型，不代表已开通服务。

科研中枢仅提取厂商“科研超级中枢”首页内容：读算做、快捷建议、研究输入、六类研究模板和示例研究。模板科学内容保持原样，作为独立组件融入现有平台导航，没有嵌入厂商整套原型、外层导航或其他页面，也不加载其 CDN 与业务脚本。上下文加载、模型选择、任务关联和模板详情使用本平台交互；研究执行仍为演示，不连接真实后台。

工作台本轮调整：恢复待办、研究任务、加入的课题空间和近 30 天科研产出四组指标及状态明细；产出统计可切换至近 90 天或近 1 年，均为演示数据。AI 建议采用紧凑列表与详情侧栏，只供浏览，唯一操作为「同步到科研中枢」（2026-10-13 调整，原「忽略 / 采纳 / 定时」已取消）。中枢支持加载文件、文件夹、资源中心条目和历史会话摘要，并保留来源标签。任务、待办和近期产物可进入归属课题内的具体任务详情。资源数量按类型与单位展示，不汇总异质资源。帮助入口改为问号，中枢在顶栏和右下角使用统一科学轨道图标。

课题空间的科研任务以「任务—多次会话」组织：新建任务后可创建、继续或复核会话；单次会话沙盒记录本次输入、过程文件与输出，确认后才可提升为任务长期材料。任务和会话分别提供产物视图；执行轨迹按人员输入、模型规划、工具调用和人员反馈筛选。当前运行与轨迹均为原型演示，不采集或上传真实科研数据。

对话设计参考用户提供的 Petrolab 界面，增加可见工具状态、结构化证据对比和建议追问；课题科研任务左侧可打开「CO₂ 加氢 DFT 解读」案例演示。轨迹参考厂商的时长／轮次／调用切换和事件密度轴；产物视图提供任务汇总、文件画廊及会话问答。点击产物可查看文件溯源（血缘链、复现准备、修改历史），并能定位来源轨迹。案例数值、文件及血缘均是演示素材，未经过科学核验，也不代表已完成真实计算。

材料加载为原型交互：本地文件只展示名称，不读取或上传；资源、会话、任务与数量均为演示数据。定时运行和 AI 科研执行不连接真实后台。

新版使用用户提供的「中国石油 ScienceLab · AI for Science 一体化科研平台」Logo，并延续蓝白科研产品基础。旧版原型仅用于理解石油石化科研场景、科研会话、读算做工具和资产追溯的业务深度，页面结构和代码均重新设计。


## 2026-10-02 作业监控实施

新增科学计算、模型训练、模型推理、实验验证四类执行记录，沿用同事版本的专业执行页面样式。执行关联科研任务，保存输入版本、配置快照、状态与日志；完成后的示例产物可登记到研究材料并回溯执行来源。原科研任务主体与科研资源中心布局保留。

当前仅为本地原型：确认提交、排队、运行和结果均为模拟，使用浏览器 localStorage 按课题保存。尚未连接 AI 中台或真实实验设施，结果登记后仍为待复核材料。

### 2026-10-02 导航与任务协作收拢

取消独立协作与评审、研究结论导航；旧协作入口转科研任务，旧结论入口转关键问题。空间文件保留上方路径、下方直接列出具体文件及创建者筛选。任务评审记录保存在浏览器本地，不发送真实通知，不代表真实身份权限或科研评审。当前代码检查通过，浏览器页面验证因连接超时尚未完成。
