# 科研知识中心系统审计（2026-10-09）

> 修复状态：2026-10-09 已完成本报告中 P0/P1 布局、字号与焦点问题的首轮修复。页面状态水平溢出扫描均为 0，详见本次任务的验证记录。

## 结论

页面比例问题不是单个组件的尺寸误差，而是三层样式上下文冲突：

1. Vite 资源入口的 `<main id="v-main">` 没有 `.v-app` 和 `.v-main` 上下文，导致品牌变量未定义、基础内边距缺失。
2. 旧全局 `v1.css` 与新知识中心 CSS 重复定义同名选择器，结果页栏宽被反向覆盖。
3. 知识资产页使用 `margin: -22px -24px` 抵消本应存在的 `.v-main` padding，但嵌入模式中 padding 实际为 0，因而产生 24px 水平溢出。

## 高优先级问题

### P0-1 检索结果页栏宽反转

- 实际：结果列表宽 210px，概览侧栏宽 1039px；中文标题和操作按钮逐字换行。
- 期望：结果列表自适应，右侧概览固定 242–286px。
- 根因：`knowledge-results.css:191` 定义了正确布局，但 `v1.css:3615` 的旧 `.v-knowledge-results-layout { grid-template-columns: 210px minmax(0, 1fr) }` 覆盖了它。
- 证据：`screenshots/05-results.png`

### P0-2 主操作按钮文字不可见

- 实际：专利详情的“加入 Research Agent”按钮呈现为空白按钮。
- 计算样式：文字白色，背景透明，边框白色。
- 根因：`--v-brand` 只定义在 `.v-app`，资源入口没有 `.v-app`；`.v-button.primary` 的 `background: var(--v-brand)` 因变量缺失而失效。
- 证据：`screenshots/07-patent-detail.png`

### P0-3 知识资产和图谱页持续水平溢出

- 实际：知识库列表/详情、图谱列表/详情的页面 `scrollWidth=1289`，`clientWidth=1265`，底部始终有水平滚动条。
- 溢出源：`.v-knowledge-asset-heading` 从 `x=-24` 开始，宽 1313px，右边到 1289px。
- 根因：`knowledge-asset-views.css:7` 的负 margin 和嵌入入口的 0 padding 不匹配。
- 证据：`08-knowledge-library.png`、`09-knowledge-library-detail.png`、`10-graph-catalog.png`、`11-graph-detail.png`

## 中优先级问题

### P1-1 外层导航使内页提前进入紧凑断点

- 1440×900 桌面视口中，左侧导航占 252px，iframe 实际只有 1188×836。
- 知识页在 1350px 和 1050px 定义断点，因此在常规桌面窗口内已触发 `max-width:1350px` 紧凑版。
- 结果：字号、卡片、输入框和栏间距都比用户参考图更密，造成“整页被缩小”的观感。
- 证据：`01-embedded-home.png`

### P1-2 字号过小

- 资产和详情页存在大量 9px、10px、11px 文字；实测最小 9px。
- 影响：在 iframe 内页紧凑断点下，标签、元数据和说明的可读性明显下降。
- 建议：桌面辅助信息不低于 12px，正文不低于 14px，主要交互标签使用 13–14px。

### P1-3 焦点态被移除

- `knowledge-results.css:126` 对搜索、select 和 checkbox 同时设置 `outline: none; box-shadow: none`。
- 影响：键盘用户无法判断当前焦点位置，不符合可访问性要求。

### P1-4 内外层滚动上下文不统一

- 外层平台高度 900px，iframe 高 836px；知识首页内容高约 995px、有结果页高 2410px。
- iframe 内自己滚动，外层侧边栏同时保持独立滚动轨道，用户容易拖错滚动条。

## 页面步骤健康度

1. 嵌入式知识首页：**可用，比例偏紧**。
2. 智能检索首页：**可用**，但存在小字号和内层滚动。
3. 高级检索：**基本可用**，检索按钮与条件区的对齐较弱。
4. 无结果页：**可用**，有“放宽筛选”恢复路径。
5. 有结果页：**严重失效**，结果列表被压至 210px。
6. 文献详情：**基本可用**，但右侧 AI 面板进一步压缩正文宽度。
7. 专利/标准/数据集通用详情：**存在阻断问题**，主按钮不可见。
8. 知识库列表：**可用但布局异常**，持续水平溢出。
9. 知识库详情：**可用但布局异常**，持续水平溢出。
10. 知识图谱目录：**可用但布局异常**，页面级水平溢出。
11. 知识图谱详情：**可用但布局异常**，水平滚动与内部图谱画布叠加。

## 建议修复顺序

1. 先统一嵌入根节点上下文：在资源入口提供 `.v-app` 的主题变量，并明确 embedded main 是否拥有 24px padding。
2. 删除或隔离 `v1.css` 中的旧知识中心选择器，避免与 `knowledge-*.css` 同名。
3. 取消知识资产标题的负 margin 补偿，改为嵌入模式显式布局。
4. 断点改为基于内容容器的实际可用宽度，不再假设整个浏览器宽度都属于内页。
5. 字号与键盘焦点作为同一轮可访问性修复。

## 建议验收标准

- 1440×900 与 1920×1080 桌面视口下，所有 11 个状态无页面级水平滚动条。
- 有结果页的结果列表宽度≥65%，概览侧栏 240–320px；标题不出现逐字换行。
- 所有 primary 按钮都有可见背景和≥4.5:1 文字对比度。
- 主要交互文字≥13px，辅助文字≥12px。
- Tab 遍历时，搜索框、筛选器、checkbox、返回和主操作均有清晰焦点环。
- 外层平台只保留一个主滚动语义，不让用户在侧边栏与 iframe 之间猜测滚动目标。
